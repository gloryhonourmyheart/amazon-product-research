## 技术栈建议

### 后端
- **语言**: Node.js 20+（性能好，生态成熟）
- **框架**: Express.js（轻量灵活）
- **数据库**: MySQL 8.0+（稳定，社区活跃）
- **ORM**: Sequelize（简化数据库操作）
- **API文档**: Swagger（自动生成API文档）

### 前端（已有）
- **框架**: Vue 3（Composition API）
- **UI**: Bootstrap 5
- **图表**: Chart.js 4.x
- **图标**: Font Awesome 6

## 亚马逊API申请流程

1. **注册亚马逊开发者账号**
   - 访问 https://developer.amazonservices.com/
   - 使用亚马逊卖家账号登录

2. **创建SP-API应用**
   - 创建新应用
   - 填写应用信息
   - 获取Client ID和Client Secret

3. **配置IAM角色**
   - 在AWS IAM中创建角色
   - 配置权限策略
   - 关联卖家账号

4. **获取访问令牌**
   - 使用OAuth 2.0授权流程
   - 获取refresh token

5. **开始调用API**
   - 产品数据API: Products API
   - 评论数据API: Reviews API
   - 关键词数据: 需要第三方工具

## 数据采集方案对比

| 方案 | 优点 | 缺点 | 成本 |
|------|------|------|------|
| **亚马逊SP-API** | 官方合规，数据准确 | 调用限制，审核严格 | 低（免费额度） |
| **爬虫采集** | 数据全面，灵活 | 反爬风险，法律风险 | 中 |
| **第三方数据供应商** | 快速获取，无需开发 | 费用高，数据延迟 | 高 |
